### 🧭 About Me

I'm a **Java & MERN Full Stack Developer** and a **2024 B.Tech CSE graduate from Dr. M.G.R. Educational and Research Institute, Chennai**, open to full-time software engineering roles.

I design, build, and deploy high-performance applications spanning **Java 17 / Spring Boot** and the **MERN stack (MongoDB, Express.js, React 18, Node.js)**. My background includes architecting secure RESTful APIs, building stateless JWT authentication flows, integrating payment workflows (Razorpay with cryptographic signature verification), and delivering responsive, mobile-first interfaces.

I handle end-to-end deployments across **AWS (EC2, CloudFront, RDS, S3)** with **Nginx reverse proxies**, **Docker containerization**, and automated **GitHub Actions CI/CD pipelines**, while integrating **Google Gemini GenAI** into production workflows.

**🎯 Open to:** Full Stack Developer (Java / MERN) · Backend Developer (Spring Boot / Node.js) · Frontend Developer (React.js)
